## 1. 它是什么

桌上有一个**带摄像头的小盒子**，旁边有一个**小风扇**和一盏**红色小灯**。

它会做三件事：

1. **看**：每 10 秒拍一张你的照片
2. **判**：把照片发到云端，让 AI 判断你有没有低头、驼背、歪身子
3. **提醒**：如果你**连续两次**（约 20 秒）都不端正，就让风扇吹你 5 秒、红灯亮起

它**不会**：录像、录音、保存你的照片、评判你的学习内容。

> 照片会发到云服务器上判断，判断完就丢掉，服务器不保存。

## 2. 开机前：把摄像头摆对

**这一步最重要。摆错了，它会一直误判。**

| 要求 | 说明 |
|---|---|
| **位置** | 桌子正前方，正对你的脸 |
| **高度** | 和你的头差不多高，**平视**（不要俯拍、不要仰拍） |
| **距离** | 离你的脸 **0.5~0.6 米**（大约一臂远） |
| **角度** | 镜头正对，**不要斜着放** |
| **光线** | 能看清你的脸；**不要背对窗户**（会逆光变成黑影） |

**正确摆法**：能拍到你的**头和两肩**，画面里你大概占中间三分之一。

**❌ 常见错误**

- 放得太低 → 只拍到胸口，看不到头
- 放得太远 → 人在画面里很小，AI 看不清
- 斜着放 → 会把你判成"歪身子"
- 背光 → 画面一片黑，判定"看不清"，不提醒

> 💡 摆好后**不要再动它**。移动了就要重新调（见 §9 第 1 条）。

## 3. 怎么开机、怎么关机

### 开机

**接通电源就行**（USB 线或电池）。

- 通电后大约 **10 秒**，它会拍第一张照片
- 不需要按任何按钮

### 关机

**直接断电**。

- 它不会保存任何数据，下次开机会从头开始
- 断电后红灯熄灭、风扇停止是正常的

> ⏱ 每次断电重启后，"连续 2 帧"的计数会清零，
> 所以刚开机的头 20 秒内不会吹风，这是正常的。

## 4. 它会怎么提醒你

### 时间线（假设你从第 0 秒开始驼背）

```
0 秒     拍第 1 张 → 判定"不端正"（第 1 次）
10 秒    拍第 2 张 → 判定"不端正"（第 2 次，够了！）
         👉 风扇开始吹 + 红灯亮
15 秒    风扇自动停，红灯灭
70 秒    如果你还驼着背 → 再吹 5 秒
```

### 三条规则

| 情况 | 它会怎么做 |
|---|---|
| 只是低头捡个笔（几秒） | **不吹**（不足 20 秒） |
| 持续驼背约 20 秒 | 吹 **5 秒** + 红灯 |
| 一直不改正 | 每 **60 秒**吹一次（不会连续吹个不停） |
| 你坐直了 | **马上停**，红灯灭 |

> 🎯 设计思路：**只提醒"持续"的不端正**，不打扰偶尔的动作。

---

## 5. 灯的三种状态

| 红灯 | 风扇 | 含义 |
|---|---|---|
| 灭 | 停 | ✅ 正常监测中 |
| 亮 | 转 | ⚠️ 正在提醒你（5 秒） |
| 亮 | 停 | 当前版本**不会出现**（这是旧的"免打扰"状态，功能已关闭） |

> 如果看到"红灯亮但风扇不转"且一直不恢复，说明设备卡住了，按 §10 断电重启。

## 6. 什么情况下它不会提醒你

这些是**故意的设计**，不是坏了：

| 情况 | 为什么 |
|---|---|
| **房间太暗 / 晚上没开灯** | 看不清你的姿势，宁可不管也不误吹 |
| **你离开座位** | 画面里没人，不判断 |
| **你戴着口罩/帽子遮住脸** | 找不到关键点，不判断 |
| **刚开机 20 秒内** | 还没攒够两次判断 |
| **WiFi 断了** | 传不上去，这个周期跳过（恢复后自己继续） |

> 💡 原则：**宁可漏掉，也不误吹**。它不会因为看不清就乱吹你。

## 7. 想安静一会儿怎么办

当前版本**没有静音按钮**（设计上那个按钮和摄像头冲突，已经关掉了）。两个临时办法：

### 办法一：盖住镜头（推荐，最安全）

用一张纸或不透光的布盖住摄像头。

- ✅ 效果：立刻停止判定，不吹
- ⚠️ 注意：盖着的时候完全不监测
- 拿开后自动恢复

### 办法二：拔掉风扇线（保留监测）

把风扇的电源线从电路上拔掉。

- ✅ 效果：红灯照样亮，但不吹风（安静提醒）
- ⚠️ 注意：拔插时**先断电**，不要带电操作

### 办法三：断电

直接关掉，想用时再开。

## 8. 日常维护

| 项目 | 怎么做 | 频率 |
|---|---|---|
| **镜头** | 用眼镜布轻轻擦，不要用纸巾干擦（会划花） | 每周或发现画面模糊时 |
| **电池充电** | TP4056 红灯=正在充，蓝灯=充满；可以边充边用 | 电量低时 |
| **风扇** | 用牙签/软毛刷清扇叶上的灰 | 每月 |
| **接线** | 检查杜邦线有没有松、有没有被扯到 | 每月 |
| **散热** | 不要用东西盖住板子（摄像头模组会发热） | 平时注意 |

> ⚠️ **不要热插拔摄像头排线**。要动排线一定先断电，否则会烧坏摄像头。

## 9. 常见疑问

### 1. 我明明坐直了，为什么还被吹？

按可能性排序：

1. **摄像头被移动过** → 位置一变，原来的判定标准就不准了（需要重新标定，找维护的人）
2. **光线变了**（比如晚上换了台灯）→ 明暗变化会影响判定
3. **你换了椅子/桌子高度** → 拍摄角度变了
4. **穿了大面积浅色/深色衣服** → 偶尔会影响关键点识别
5. **画面里出现了第二个人或大幅海报** → 单人设计，会被干扰

**临时缓解**：把摄像头重新摆正到 §2 的位置，观察 10 分钟。

### 2. 我驼背很久了，它怎么不吹？

依次检查：

1. **灯是不是亮的** → 不亮说明没通电
2. **房间是不是太暗** → 开灯
3. **你在画面里吗** → 用手在镜头前晃一下（需要有人帮你看画面，或用 `http://设备IP/capture`）
4. **是不是刚开机不到 20 秒** → 等一下
5. **离得是不是太远** → 挪近到 0.5~0.6 米

### 3. 风扇转，但我感觉不到风

- 调整出风口，对着**手背**吹（设计就是吹手，不吹脸）
- 检查扇叶有没有被线缠住
- 风扇声音大但没风 → 可能装反了，或者扇叶脏了

### 4. 它会不会一直吹、吹个不停？

**不会。**

- 每次只吹 **5 秒**
- 两次之间至少隔 **60 秒**
- 你坐直它**立刻停**

### 5. 我能用手机/电脑看自己的坐姿吗？

目前**没有手机 App**（还在设计阶段）。
技术人员可以用电脑网页看摄像头实时画面，但这属于调试功能。

### 6. 可以两个人一起用吗？

**不行。** 它按"单人固定用户"设计，画面里出现第二个人会导致判定混乱。

### 7. 照片会被存下来吗？会不会泄露隐私？

- 照片发到云服务器 → 判断 → **立刻丢弃**
- 服务器**不存照片、不存录像、不建数据库**
- 但照片确实**经过网络传输**到云服务器（这一点已接受）

### 8. 一晚上要耗多少电？

- 设备本身约 **150~250 mA @5V**（峰值 500 mA）
- 2000 mAh 电池 + 偶尔吹风，大约能撑 **8~11 小时**
- 风扇启动瞬间电流较大，所以 5V 端有大电容缓冲

### 9. 它会不会记录我学习多久？

**不会。** 阶段一不做时长统计、不做日报。这些是二期功能。

## 10. 出问题了怎么自查

### 三步判断

**第 1 步：看电**

- 红灯完全不亮 → 检查电源线、开关、电池是否有电
- 通电后风扇**立刻**转个不停 → 断电，找维护的人（可能是接线短路）

**第 2 步：做一次"驼背测试"**

坐直 1 分钟 → 不吹；刻意低头驼背 20 秒 → 应该吹 5 秒。

- 两个都正常 → 设备没问题
- 都不动 → 大概率是 WiFi 断了（找维护的人看串口日志）
- 一直吹 → 大概率是摄像头位置/光线变了（见 §9 第 1 条）

**第 3 步：重启**

断电 → 等 5 秒 → 重新通电 → 等 30 秒再测。

> 90% 的临时问题，重启都能解决。

### 还是不行？

把下面这些信息告诉维护的人，能大幅加快排查：

| 要记录的信息 | 怎么得到 |
|---|---|
| 什么时候开始的 | 大致时间 |
| 灯是什么状态 | 亮/灭/闪 |
| 风扇有没有转 | 转/不转 |
| 当时光线如何 | 开灯/关灯/白天 |
| 摄像头有没有被移动 | 有/没有 |
| 电源是什么 | USB / 电池 |

## 11. 安全须知

| ⚠️ 事项 | 原因 |
|---|---|
| 不要拆开电池组 | 18650 锂电池短路会起火 |
| 电池正负极不要接反 | 保护板没有防反接，接反会烧毁 |
| 不要用金属物捅电路板 | 会短路 |
| 不要带电插拔摄像头排线 | 会烧摄像头 |
| 风扇被卡住时立即断电 | 电机堵转会发热 |
| 不要放在潮湿、有水的地方 | 电路板怕水 |
| 板子发热明显（烫手）时断电 | 可能供电异常 |

> 本装置使用 5V 低压，正常使用是安全的；
> 但**锂电池**部分需要格外小心。
