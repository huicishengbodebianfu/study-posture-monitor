# 固件说明（ESP32-CAM）

> 本目录是 ESP32-CAM 的 Arduino 固件。它负责：定时拍照 → 上传云端 →
> 根据云端返回的指令控制风扇和 LED，并处理免打扰按钮。

## 1. 硬件准备

| 部件 | 说明 |
|------|------|
| 开发板 | AI Thinker ESP32-CAM（**必须带 PSRAM**，OV3660 或 OV2640 均可） |
| 下载器 | USB-TTL（CH340/CP2102），用于烧录和供电 |
| 风扇 | 5V 无刷涡轮鼓风机（4010/4020/5015，双滚珠，≤0.3A，**2 线**；经 S8050 三极管/MOS 管或驱动板接 GPIO13） |
| LED | 红色 LED（串 220Ω 电阻接 GPIO14） |
| 按钮 | 直接用板载 BOOT 键（GPIO0），无需额外接线 |

> **为什么必须带 PSRAM？**
> 摄像头拍一张 JPEG 需要一块较大的内存缓冲，ESP32 内部 RAM 不够，
> 必须靠板载的 PSRAM（额外 4MB 内存）才能正常拍照。
> 买板子时务必确认商品描述里有 "PSRAM" 字样。

> 接线详见 [../docs/接线图.md](../docs/接线图.md)

## 2. 软件环境

### 2.1 Arduino IDE 配置

1. 安装 [Arduino IDE 2.x](https://www.arduino.cc/en/software)
2. **文件 → 首选项 → 附加开发板管理器网址**，填入：
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
   （这一步是告诉 Arduino IDE 去哪里下载 ESP32 的支持包）
3. **工具 → 开发板 → 开发板管理器**，搜索 `esp32`，
   安装 **esp32 by Espressif Systems**（建议 2.0.x 版本）
4. **工具 → 管理库**，安装以下两个库：
   - `esp32-camera`（Espressif）—— 驱动摄像头
   - `ArduinoJson`（Benoit Blanchon，6.x）—— 解析云端返回的 JSON

### 2.2 开发板设置

烧录前，在 **工具** 菜单里按下表设置：

| 项目 | 值 | 说明 |
|------|-----|------|
| 开发板 | AI Thinker ESP32-CAM | 选对板子型号 |
| Flash 频率 | 80MHz | 默认即可 |
| Flash 模式 | QIO | 默认即可 |
| 分区方案 | Huge APP (3MB No OTA/1MB SPIFFS) | **必须选这个**，否则程序太大装不下 |
| 上传速度 | 115200 | 稳定优先 |
| 端口 | 你的 USB-TTL 串口 | 在设备管理器里看是哪个 COM 口 |

## 3. 配置

打开 `config.h`，修改以下**必填项**（其余保持默认即可）：

```c
#define WIFI_SSID       "你的WiFi名称"
#define WIFI_PASSWORD   "你的WiFi密码"
#define SERVER_URL      "http://你的服务器IP:8000/detect"
#define DEVICE_KEY      "与云端一致的密钥"
```

**注意事项**：

- `SERVER_URL` 里的 IP 是**云服务器的公网 IP**，端口要和云端一致（默认 8000）。
- `DEVICE_KEY` 必须和云端 `.env` 文件里的 `DEVICE_KEY` **完全一致**，
  否则云端会返回 401 拒绝。
- WiFi 建议用 **2.4GHz**（ESP32 不支持 5GHz）。

`config.h` 里还有一组**行为参数**（一般不用改）：

| 参数 | 默认 | 含义 |
|------|------|------|
| `UPLOAD_INTERVAL_MS` | 10000 | 上传间隔（毫秒），即 10 秒 |
| `BLOW_DURATION_MS` | 5000 | 每次吹风时长（毫秒），即 5 秒 |
| `SNOOZE_DURATION_MS` | 300000 | 免打扰时长（毫秒），即 5 分钟 |
| `PIN_FAN` | 13 | 风扇 PWM 引脚 |
| `PIN_LED_RED` | 14 | 红色 LED 引脚 |
| `PIN_BUTTON` | 0 | BOOT 键引脚 |

## 4. 烧录步骤

1. **接线**：USB-TTL 与 ESP32-CAM 按下表连接：

   | USB-TTL | ESP32-CAM |
   |---------|-----------|
   | TX | U0R (RX0) |
   | RX | U0T (TX0) |
   | GND | GND |
   | 5V | 5V |

2. **进入下载模式**：将 GPIO0 接 GND，按一下 RST 键。
   （这一步是让 ESP32 进入"等待接收程序"的状态）
3. Arduino IDE 点击 **上传**（右上角箭头按钮）。
4. 上传完成后：**断开 GPIO0 与 GND**，按 RST 键重启。
5. 打开串口监视器（波特率 **115200**），查看日志。

**正常启动日志示例**：

```
[BOOT] 学习状态监测系统 启动
[WiFi] 连接中...
[WiFi] 已连接, IP=192.168.1.100
[CAM]  摄像头初始化成功
[STATE] NORMAL
[UPLOAD] 上传成功, 响应: {"action":"none","upright":true}
```

## 5. 状态机说明

固件核心是一个**三态状态机**，用 `millis()` 计时，全程不阻塞。

```
        ┌──────────────────────────────────────────┐
        │                                          │
        ▼                                          │
   ┌─────────┐  云端返回 blow   ┌──────────┐  5s  │
   │ NORMAL  │ ───────────────▶ │ BLOWING  │ ─────┘
   └─────────┘                  └──────────┘
        │  ▲
  短按  │  │ 5min 到 / 再按
  BOOT  ▼  │
   ┌──────────┐
   │  SNOOZE  │
   └──────────┘
```

| 状态 | 行为 | 进入条件 | 退出条件 |
|------|------|----------|----------|
| NORMAL | 每 10s 拍照上传；LED 灭；风扇停 | 上电 / 吹风结束 / 免打扰结束 | 收到 blow → BLOWING；按 BOOT → SNOOZE |
| BLOWING | 风扇满速 5s；LED 亮 | 云端返回 `blow` | 5 秒定时到 → NORMAL |
| SNOOZE | 不上传；LED 常亮 | 短按 BOOT | 5 分钟到 / 再按 BOOT → NORMAL |

**为什么用状态机而不是 `delay()`？**

如果用 `delay(5000)` 来吹风，这 5 秒内程序什么都干不了——
按钮按了没反应、WiFi 断了不知道。用状态机 + `millis()` 计时，
程序始终在循环里跑，可以随时响应按钮、检查 WiFi，体验更好。

## 6. 代码结构

`main.ino` 是单文件程序，主要包含：

| 函数 | 作用 |
|------|------|
| `setup()` | 初始化串口、摄像头、WiFi、电机 PWM、按钮 |
| `loop()` | 主循环：处理按钮 → 处理状态机 → 到点上传 |
| `handleButton()` | 按钮消抖 + 切换免打扰 |
| `uploadAndHandle()` | 拍照、上传、解析响应、触发吹风 |
| `setFan(speed)` | 设置风扇 PWM 占空比 |
| `setLed(on)` | 开关红色 LED |

**关键实现细节**：

- **非阻塞计时**：所有定时都用 `millis()` 差值判断，不用 `delay()`。
- **按钮消抖**：检测到电平变化后等 50ms 再确认，避免抖动误触发。
- **PWM 通道**：风扇用 LEDC channel 0，摄像头用 channel 1，避免冲突。
- **WiFi 断线**：上传失败时静默跳过，下个周期自动重试，不卡死。

## 7. 常见问题

| 现象 | 排查 |
|------|------|
| 摄像头初始化失败 | 检查是否带 PSRAM；供电是否足够（5V/2A） |
| 上传失败 code=-1 | 检查 SERVER_URL、WiFi、服务器防火墙/安全组 |
| 上传失败 code=401 | DEVICE_KEY 与云端不一致 |
| 风扇不转 | 检查 GPIO13 接线、S8050/MOS 管、电机供电 |
| 频繁重启 | 供电不足，加大电容或换更大电流电源 |
| 串口无输出 | 波特率是否 115200；USB-TTL 接线是否 TX/RX 交叉 |
| 一直上传失败 | WiFi 是否 2.4GHz；服务器 IP 是否正确 |
