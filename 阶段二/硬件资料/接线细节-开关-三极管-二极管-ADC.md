# 阶段二 · 接线细节详解（开关 / S8050 / 1N5819 / 电池 ADC）

> 配套：`接线图-阶段二-定稿.md`、`无升压模块应急供电.md`
> 目标：把四个最容易接错的点讲到“照着做就能通”。
> 工具：万用表（通断/二极管/直流电压挡）、电烙铁、热缩管、镊子。

---

## 0. 先记住三句话

1. **三脚摇臂开关没有极性**，只用 **COM + 一个触点（NO 或 NC）**，第三脚空着。
2. **S8050 是 NPN**，常见 TO-92 字面朝自己、引脚朝下：**左 E – 中 B – 右 C**；中间是基极。
3. **1N5819 带环端 = 阴极（K）**；在本电路里 **带环端接 5V**，另一端接风扇负极/集电极。

---

## 1. 三脚摇臂开关（SPDT）怎么接

### 1.1 三个脚是什么

三脚摇臂/拨动开关绝大多数是 **SPDT（单刀双掷）**：

| 脚 | 名称 | 含义 |
|---|---|---|
| COM | 公共端 | 刀，始终参与导通 |
| NO | 常开端 | 开关拨到一边时与 COM 通 |
| NC | 常闭端 | 开关拨到另一边时与 COM 通 |

> 实物三脚一排时，**中间脚常见是 COM**，两侧是 NO/NC；但不同厂家会换位置，**必须用万用表确认**。
> 如果开关带灯（3 脚：+、负载、−），那不是普通开关，别按本接法用。

### 1.2 万用表找 COM / NO / NC（30 秒）

1. 万用表打到 **通断挡（蜂鸣）**。
2. 开关拨到 **A 位**，测三对脚（1-2、1-3、2-3）：
   - 哪一对响，就是“COM + 当前闭合的那一侧”。
3. 开关拨到 **B 位**，再测三对：
   - 另一对响。
4. **两次都参与导通的那只脚 = COM**；另外两只分别是 NO / NC。

举例：A 位 1-2 响，B 位 1-3 响 → **1 = COM，2/3 = NO/NC**。

> 如果发现有一对脚**始终导通**、第三脚怎么拨都不通，可能是 SPST/带灯结构；
> 只用“会通断”的那一对，第三脚空着，不要硬接。

### 1.3 接线（只用 COM + NO）

```
ESP32 GPIO47 ──▶ COM（公共端）
NO（常开端） ──▶ GND
NC（常闭端） ──▶ 空着，剪短/热缩绝缘
```

- 固件 `INPUT_PULLUP`：**闭合到 GND = LOW = 免打扰（SNOOZE）**。
- 选 **NO** 或 **NC** 都可以，区别只是“拨到哪边算安静”：
  - 用 NO：拨到“安静”位时 COM-NO 闭合 → LOW → 免打扰。
  - 用 NC：逻辑相反，拨到另一边才安静；建议用 NO，和面板标识一致。
- 开关**没有极性**，COM/NO 接反不影响；只要保证“安静位闭合到 GND”。

### 1.4 验收

- 拨到安静位：红灯常亮，`http://<板IP>/status` → `"quiet_switch":true`。
- 拨回：红灯灭/绿灯亮，`"quiet_switch":false`。
- 若一直不触发：检查是不是把开关接到了 3V3（应接 GND）、是不是还接在旧图 GPIO41。

## 2. 风扇驱动 S8050（TO-92）怎么接

### 2.1 引脚识别

常见 S8050（TO-92）**字面（有字的一面）朝自己、引脚朝下**：

```
        ┌─────────┐
        │  S8050  │   ← 字面朝自己
        └─┬─┬─┬───┘
          │ │ │
          E B C       左 → 右：E（发射极）– B（基极）– C（集电极）
```

- **中间脚 = B（基极）**。
- 左脚 = E（发射极），右脚 = C（集电极）。
- 用 **NPN 的 S8050**，不要拿成 **PNP 的 S8550**（接法相反，风扇不转）。

### 2.2 万用表确认（可选但推荐）

万用表 **二极管挡**：

1. 红表笔（+）固定在一只脚，黑表笔分别碰另外两只：
   - 两次都显示 **0.6~0.7V** → 红表笔这只脚是 **B（基极）**。
2. 红笔接 B、黑笔接 E/C 应导通；反过来（黑笔接 B）应 **OL / 不导通**。
3. 确认 B 是中间脚后，按“左 E、右 C”接。
   - 若你的表测出 B 不在中间，说明这批管子引脚顺序不同，**以 datasheet/实测为准**，不要硬套。

> 也可以用万用表 hFE 插座：NPN、E-B-C 插入，读数正常（几十~几百）即可。

### 2.3 完整接线

```
ESP32 GPIO21 ──▶ 220Ω ──▶ S8050 B（中间脚）
                   │
                   └──▶ 10kΩ ──▶ GND        ← 下拉，上电风扇不转

S8050 E（左脚） ──▶ GND 汇流排
S8050 C（右脚） ──▶ 风扇负极（黑线）
5V 母线        ──▶ 风扇正极（红线）

1N5819：带环端（阴极）──▶ 5V
        另一端（阳极）──▶ 风扇负极 / C（集电极）

100nF：并联在风扇红/黑线之间，靠近风扇
```

### 2.4 为什么这样接

- 风扇电流约 100~250mA，GPIO 只能出几 mA，**必须用三极管做低边开关**。
- 基极电流 `Ib ≈ (3.3V − 0.7V) / 220Ω ≈ 12mA`；S8050 hFE 约 100~400，足以让集电极通过 200mA 并进入饱和。
- `10kΩ` 下拉保证上电/复位瞬间 B 为低，风扇不转。
- `1N5819` 是续流二极管：风扇断电瞬间，电感电流从风扇负极经二极管流回 5V，把尖峰钳住，保护三极管。
- `100nF` 消电机换向噪声。

### 2.5 测试电压（上电自检 200ms 脉冲时）

| 测点 | 正常值 | 说明 |
|---|---|---|
| GPIO21 对 GND | 3.3V（脉冲期间） | 固件自检/吹风时 |
| B 对 GND（Vbe） | 0.6~0.8V | 基极导通 |
| C 对 GND（Vce） | 0.1~0.3V | 三极管饱和 |
| 风扇两端 | 4.7~5.0V | 风扇转 |
| E 对 GND | 0V | 接地良好 |

- Vbe = 0：GPIO 没输出/固件没跑/电阻虚焊。
- Vbe > 1V：基极电阻过大或 B 脚接错。
- Vce > 1V：没饱和（E/C 接反、管子型号不对、基极电流不足），风扇会弱、管子发热。
- 风扇反转：把风扇红/黑对调（有刷电机换向）；不要改三极管接法。

### 2.6 常见错误

1. **E/C 接反**：风扇不转或很弱，三极管发热。
2. **B 脚没串 220Ω**：GPIO 可能烧。
3. **10k 下拉没接**：上电瞬间风扇抽动。
4. **用 S8550（PNP）**：不工作。
5. **1N5819 接反**：风扇一开就短路。
6. **风扇红/黑接反**：反转，风往壳里吹。

## 3. 1N5819 二极管怎么区分正负

### 3.1 外观

1N5819 常见 **DO-41 黑色圆柱**，一端有 **银色/白色环**：

```
   无环端                     带环端
   ────────[ 黑色圆柱 ]────●────
   阳极 A（+）              阴极 K（−）
```

- **带环端 = 阴极 K**。
- 另一端 = 阳极 A。
- 符号：三角形指向竖线；**竖线/带环端是阴极**。

### 3.2 万用表判断（二极管挡）

| 红表笔（+） | 黑表笔（−） | 读数 | 结论 |
|---|---|---|---|
| 阳极（无环端） | 阴极（带环端） | 0.2~0.3V | 正向导通，正常 |
| 阴极（带环端） | 阳极（无环端） | OL / 不导通 | 反向截止，正常 |

> 记忆：**红笔接的那端是阳极，黑笔接的那端是阴极**（导通时）。
> 如果读数反了，说明表笔/管子与预期相反，以实测为准。

### 3.3 在本电路里的方向

```
5V 母线 ──▶ 带环端（阴极 K）
风扇负极 / S8050 C ──▶ 无环端（阳极 A）
```

- 也就是：**带环端朝 5V**。
- 正常工作时，阴极在 5V、阳极在 0V 左右，二极管 **反向截止**，不影响风扇。
- 风扇关断瞬间，风扇负极电压冲到 5V 以上，二极管 **正向导通**，把尖峰泄放到 5V，保护三极管。

### 3.4 接反的后果

接反 = 阳极接 5V、阴极接 C：
- 风扇一转，C 接近 0V，二极管从 5V 正向导通到 GND → **近似短路**；
- 二极管/三极管/电源至少坏一个。
- 所以焊前一定核对 **带环端朝 5V**。

### 3.5 常见错误

1. 把“带环端”当正极（错）：**带环端是阴极**，本电路接 5V。
2. 用 1N4007 代替 1N5819：也能凑合，但压降大、恢复慢；优先 1N5819。
3. 二极管与风扇并联时跨错端子：应跨在 **风扇+ 与风扇−** 之间（也就是 5V 与 C 之间）。

## 4. 电池电量检测（10k + 10k）详细

### 4.1 原理

ESP32 ADC 最大 3.3V，18650 满电 4.2V，不能直连。用两只 10k 做 **1:1 分压**：

```
BAT+（船型开关之后、TP4056 B+ 节点）
   │
  10kΩ（上，1%）
   │
   ├──────────▶ ESP32 GPIO1（ADC1_CH0）
   │
  10kΩ（下，1%）
   │
  GND（系统 GND / TP4056 OUT−）
```

- 分压比 = `R下 / (R上 + R下) = 10k / 20k = 1/2`
- `V_GPIO1 = V_BAT / 2`
- 满电 4.20V → 2.10V；低电 3.30V → 1.65V。

### 4.2 两个“地”别接错

| 接点 | 接到 | 不要接到 |
|---|---|---|
| 分压上端 | 船型开关之后的 **BAT+**（TP4056 `B+` 节点） | 5V 母线（升压后的 5V，会烧 ADC） |
| 分压下端 | **系统 GND**（TP4056 `OUT−`） | `B−`（保护板动作时读数会跳） |
| 分压中点 | **GPIO1** | GPIO2（板载 LED 占用） |

- 上端接在开关之后：关机就不耗电。
- 分压电流 `4.2V / 20kΩ = 0.21mA`，可忽略。
- 可选：GPIO1 对 GND 并 **100nF**，滤采样噪声。

### 4.3 固件怎么算

`config.h`：

| 参数 | 值 | 含义 |
|---|---|---|
| `BAT_ADC_RESOLUTION` | 4095.0 | 12 bit |
| `BAT_ADC_VREF` | 3.3V | ADC 参考 |
| `BAT_DIVIDER_RATIO` | 2.0 | 1:1 分压 |
| `BAT_FULL_VOLTAGE` | 4.20V | 满电 |
| `BAT_LOW_VOLTAGE` | 3.30V | 低电阈值 |
| `BAT_CHECK_INTERVAL_MS` | 30000 | 30 秒采一次 |

代码等价于：

```
V_GPIO1 = raw / 4095 × 3.3
V_BAT   = V_GPIO1 × 2.0
```

### 4.4 预期读数表（1:1 分压）

| 电池电压 | GPIO1 电压 | 12bit 原始值（约） | `/status` battery_v |
|---:|---:|---:|---:|
| 4.20V | 2.10V | 2606 | 4.20V |
| 4.00V | 2.00V | 2482 | 4.00V |
| 3.70V | 1.85V | 2296 | 3.70V |
| 3.30V | 1.65V | 2048 | 3.30V |
| 3.00V | 1.50V | 1861 | 3.00V |

> ESP32 ADC 未校准，实际会有 ±0.05~0.15V 误差；`/status` 与万用表差 0.1~0.2V 属正常。
> `battery_valid` 的判断范围是 **2.5V ≤ V ≤ 5.2V**（乘 2 之后）；悬空时显示 `BAT --`。

### 4.5 验收步骤

1. **断电**，万用表量电池正负极：3.0~4.2V。
2. 量 **GPIO1 对 GND**：应约为电池电压的 **一半**。
3. 上电，浏览器打开 `/status`：
   - `"battery_valid":true`
   - `"battery_v"` 与万用表差 ≤0.2V。
4. 电池低于 3.30V 时：`"battery_low":true`，状态灯转黄。
5. 拔掉电池（USB 供电）：`"battery_valid":false`、OLED `BAT --`，正常。

> **USB 只供、不装电池**：电池检测可以不做；`BAT --` 正常。
> 但 **GPIO1 不要悬空**——用 **10k 下拉到 GND**，让固件稳定读到 0V，避免悬空偶发落入 2.5~5.2V、误报 `battery_low` 黄灯。
> 分压的 2 只 10k + 100nF 可省；**风扇基极的 10k 下拉仍要装**，别混。

### 4.6 常见错误与现象

| 现象 | 原因 | 处理 |
|---|---|---|
| `BAT --` / `battery_valid:false` | 分压没接、GPIO1 悬空、地没通 | 量 GPIO1 电压；查 10k 两端 |
| `battery_v` ≈ 0 | 上端没接 BAT+ / 下端没接 GND | 逐点通断 |
| `battery_v` 偏高（如 5.0V） | 上端接到了 5V 母线 | 改接 BAT+ |
| `battery_v` 偏低约 1/3 | 用了 20k+10k（比例 1/3），固件仍按 2.0 | 换回两颗 10k，或改 `BAT_DIVIDER_RATIO=3.0` |
| `battery_v` 偏高约 1/3 | 用了 10k+20k（比例 2/3），固件仍按 2.0 | 换回两颗 10k，或改比例 |
| 读数乱跳 | 没并 100nF、线太长、地噪声 | 加 100nF，缩短线，单点接地 |
| `battery_low` 常 true | 电池真的低 / 比例错 / 地接 B− | 量电池、查比例、改接 OUT− |

### 4.7 可选校准

如果误差稳定（比如总是高 0.1V），可以：

- 把 `BAT_DIVIDER_RATIO` 从 `2.0` 微调为 `1.95` 或 `2.05`（按实测比例）；
- 或改用 `analogReadMilliVolts()` 做校准（需要改代码）；
- 但先确认电阻是 **1% 10k**，地是 **OUT−**，上端是 **BAT+**——大多数误差来自接错，不是 ADC。

## 5. 一张核对表

| 项 | 正确做法 | 错误做法 |
|---|---|---|
| 三脚开关 | COM→GPIO47，NO→GND，NC 悬空 | 把 NC 也接 GND / 接 3V3 |
| S8050 | E→GND，B→220Ω→GPIO21，C→风扇− | E/C 接反、B 不串电阻 |
| 1N5819 | 带环端→5V，另一端→风扇−/C | 带环端→风扇−（接反） |
| 分压上端 | 开关后 BAT+ | 5V 母线 |
| 分压下端 | 系统 GND（OUT−） | B− |
| 分压中点 | GPIO1 | GPIO2 |
| 分压电阻 | 两颗 10k 1% | 10k+20k / 20k+10k |
| 电池断开 | `BAT --` 正常 | 以为坏了 |
