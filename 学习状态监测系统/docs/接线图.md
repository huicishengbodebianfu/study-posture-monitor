## 1. 引脚分配总表

| 功能      | GPIO   | 说明                       |
| ------- | ------ | ------------------------ |
| 风扇 PWM  | GPIO13 | 经三极管（S8050）/ MOS 管驱动电机   |
| 红色 LED  | GPIO14 | 串 220Ω 限流电阻              |
| BOOT 按钮 | GPIO0  | 板载按键，免打扰                 |
| 摄像头     | 固定引脚   | 由 esp32-camera 库管理，无需手动接 |

> **为什么选 GPIO13 和 GPIO14？**
> ESP32-CAM 的可用 GPIO 不多（很多被摄像头和 PSRAM 占用）。
> 原设计为 GPIO12/13；由于 GPIO12 与板载 microSD 卡槽共用，改用 **GPIO13（风扇）/ GPIO14（红灯）**。
> 二者空闲且可输出；**不插 SD 卡时不受影响**。

> ⚠️ **下拉电阻必须保留**：在开关管控制端加 **10kΩ 下拉到 GND**，保证上电瞬间风扇不转。
> （原 GPIO12 是 ESP32 启动配置脚 MTDI，改用 GPIO13 后该隐患已消失，但下拉仍需保留。）
> GPIO13/14 同属 SD 信号组，极少数板卡带有上拉；若上电瞬间风扇轻微抖动，把下拉换成 **1kΩ** 即可。

## 2. 风扇接线

风扇电机**不能直接接 GPIO**（GPIO 只能输出微弱电流，会烧坏芯片），
必须通过**开关管**（三极管或 MOS 管）驱动。

### 2.1 接线（低边开关，S8050 三极管）

```
ESP32 GPIO13 ──▶ 220Ω 电阻 ──▶ S8050 基极(B，中间脚)
                     │
                     └── 10kΩ 下拉电阻 ──▶ GND   ← 上电时钳位为低，风扇不转
S8050 发射极(E，左脚) ──▶ GND
S8050 集电极(C，右脚) ──▶ 风扇负极(黑线)
5V 电源              ──▶ 风扇正极(红线)
1N5819               ──▶ 阴极(带环端)──▶ 5V；阳极──▶ 风扇负极(集电极)   ← 反向并联在风扇两端
100nF 陶瓷电容        ──▶ 并联在风扇红/黑线之间（贴近风扇，消噪）
```

> ⚠️ 用三极管时 **1N5819 必须接**（三极管没有体二极管，否则断电尖峰会击穿它）。

### 2.2 元件清单

| 元件 | 规格 | 作用 |
| --- | --- | --- |
| 开关管 | **S8050**（NPN，TO-92 直插） | 小电流(3.3V GPIO)控制大电流(5V 风扇) |
| 续流二极管 | **1N5819**（1A 肖特基） | 吸收电机断电反向尖峰，保护开关管 |
| 基极电阻 | **220Ω**（无 100Ω 时用 1kΩ 亦可） | 限流，保护 GPIO |
| 基极下拉电阻 | 10kΩ | 上电默认关断风扇 |

> **手头没有 100Ω？用 220Ω 或 1kΩ 完全没问题**：控制端电阻只是限制瞬间电流（稳态几乎不耗电），
> 220Ω/1kΩ 的开关时间常数远小于 5kHz PWM 周期（200µs），开关速度不受影响。
> 若只有一颗 220Ω，优先给 LED（LED 对阻值更严格）。

### 2.3 S8050 引脚识别（TO-92）

有字的一面朝自己、引脚朝下，**从左到右 = E（发射极）– B（基极）– C（集电极）**。

拿不准时用万用表二极管档验证：**红表笔接中间脚，黑表笔分别碰左右两脚，都能读出约 0.6~0.7V** → 中间脚即 B（基极）。

> ⚠️ **S8050 是 NPN**；若手头是 **S8550（PNP）则不能**用在本低边开关电路里，注意看丝印。

### 2.4 为什么需要续流二极管

电机断电瞬间会产生反向电压尖峰，可能击穿开关管。
在电机两端**反向并联** 1N5819（**带环端朝 5V**）即可吸收这个尖峰。

> ⚠️ 方向接反 = 风扇一开就短路，可能烧开关管。焊接前务必核对。

### 2.5 替代开关器件

| 方案 | 型号/模块 | 焊接难度 | 说明 |
| --- | --- | --- | --- |
| **三极管（本方案）** | **S8050**（NPN TO-92） | 好焊 | 按 §2.1；**1N5819 必接**；风扇电流建议 ≤0.3A |
| 直插 MOS | **IRLZ44N / FQP30N06L**（TO-220，逻辑电平） | 好焊 | 引脚 G–D–S；自带体二极管，1N5819 可省；**勿用 IRFZ44N/IRF540N（非逻辑电平，3.3V 驱动不导通）** |
| MOS 驱动模块 | 成品 5V MOS 模块 | 免焊 | 按模块丝印接线：VCC→5V、GND→GND、SIG→GPIO13 |
| 继电器模块 | 1 路 5V **高电平触发** | 免焊 | VCC→5V、GND→GND、IN→GPIO13；风扇串 COM/NO，有"咔哒"声 |

## 3. LED 接线

```
ESP32 GPIO14 ──▶ 220Ω 电阻 ──▶ LED 正极(长脚)
ESP32 GND    ──▶ LED 负极(短脚)
```

| 元件 | 规格 | 作用 |
| --- | --- | --- |
| 电阻 | 220Ω | 限流，防止 LED 烧毁 |
| LED | 红色 5mm | 视觉提醒 |

> **为什么必须串电阻？**
> LED 导通后电阻极小，直接接 3.3V 会因电流过大而烧毁。
> 220Ω 电阻把电流限制在约 6~10mA，安全且足够亮。

## 4. BOOT 按钮

直接使用 ESP32-CAM 板载的 **BOOT 键**（GPIO0），无需额外接线。

- **短按**：进入/退出免打扰模式（5 分钟）
- 固件已做**消抖处理**（50ms），不会因抖动误触发

> **注意**：GPIO0 在**上电时**被用于进入下载模式。
> 正常运行时它是普通输入引脚，可以当按钮用。
> 但**上电瞬间不要按住 BOOT 键**，否则会进入下载模式。

## 5. 供电方案

### 5.1 调试阶段（推荐先用）

直接用 USB-TTL 的 5V 给 ESP32-CAM 供电，简单可靠（先跑通再上电池）。

### 5.2 便携阶段（电池组）

```
18650 ──▶ TP4056(带保护板) ──▶ XL3608-5V ──▶ 5V 总线 ──▶ ESP32-CAM 5V
(B+/B−)      (OUT+/OUT−)     (IN+/IN−)   (OUT+/OUT−)    └──▶ 风扇 5V(经开关管)
                                                           │
                                                  470~1000µF 电解电容
                                                  (跨接 5V 与 GND)
```

**端子对照（关键，别接错）**：

| 模块 | 端子 | 接到 |
| --- | --- | --- |
| 18650 | 正极 / 负极 | TP4056 `B+` / `B−` |
| TP4056 | `OUT+` / `OUT−` | XL3608 `IN+` / `IN−` |
| TP4056 | Micro-USB | 充电输入（充电红灯、充满蓝灯） |
| XL3608-5V | `OUT+` / `OUT−` | 5V 总线 / GND 总线 |
| 5V 总线 | — | ESP32-CAM `5V`；风扇正极（经开关管） |

| 模块 | 规格 | 作用 |
| --- | --- | --- |
| 18650 | 锂电池 3.7V（建议 ≥2000mAh） | 供电（TP4056 保护板兜底过充/过放/短路） |
| TP4056 | **1A 充电 + 带保护板**（DW01+8205A） | 充电管理 + 过充/过放/过流/短路保护 |
| XL3608-5V | **固定 5V 升压**，约 1A 可用电流 | 3.7V→5V，给 ESP32 和风扇 |

> **为什么用 XL3608-5V**：MT3608 的可调电位器容易误调烧板；XL3608 出厂固定 5V、静态电流更低、体积更小。它是**升压**，输入须比输出低至少 0.5V（1S 电池最高 4.2V，正好满足）。

**关键**：在 5V 输出端并联一个**大电容**（470μF~1000μF，正极接 5V），
用于缓冲风扇启动瞬间的电流冲击。风扇两端再并一颗 **100nF 陶瓷电容**消噪。

> **为什么需要大电容？**
> 风扇启动瞬间电流很大，会把 5V 电压拉低，导致 ESP32 复位。
> 大电容能提供瞬时电流，稳定电压。

> 💡 功耗预算：ESP32-CAM 平均约 150~250mA @5V（峰值 ~500mA）+ 风扇约 100~300mA @5V，
> 合计在 XL3608 约 1A 范围内够用；风扇转时电池侧瞬时电流约 0.8A，18650 扛得住。
> 续航（2000mAh、风扇不常转）约 8~11 小时。

## 6. 烧录接线

烧录时 USB-TTL 与 ESP32-CAM 的连接：

| USB-TTL | ESP32-CAM |
| ------- | --------- |
| TX      | U0R (RX0) |
| RX      | U0T (TX0) |
| GND     | GND       |
| 5V      | 5V        |

**烧录步骤**：

1. GPIO0 接 GND（进入下载模式）
2. 按一下 RST
3. Arduino IDE 点上传
4. 上传完成后断开 GPIO0
5. 按 RST 重启

> **注意**：TX 和 RX 要**交叉连接**（TX→RX，RX→TX），
> 这是串口通信的基本规则。

> 💡 烧录时**建议先不接电池**，直接用 USB-TTL 5V 供电；电池接线留在联调前再接。


## 8. 注意事项

| 事项 | 说明 |
| --- | --- |
| 电机不能直连 GPIO | 必须经 S8050 / MOS 管，否则烧芯片 |
| 1N5819 方向 | **带环端(阴极)必须朝 5V**，与风扇反向并联；接反会短路烧管 |
| 用三极管必接续流二极管 | S8050 无体二极管，1N5819 不可省 |
| S8050 引脚 | TO-92：有字面朝自己、引脚朝下 = E–B–C（中间脚为 B） |
| S8050 vs S8550 | 必须用 **NPN 的 S8050**，别拿成 PNP 的 S8550 |
| 电池正负极 | TP4056 一般无防反接，**反接会烧保护板**；焊接前先量电压确认 |
| 控制端下拉电阻 | 10kΩ 下拉到 GND：上电风扇不转（改用 GPIO13 后已非启动脚，仍应保留） |
| LED 必须串电阻 | 否则烧 LED |
| 5V 端加大电容 | 470~1000µF，否则风扇启动时 ESP32 可能复位 |
| 上电勿按 BOOT | 否则进入下载模式不运行程序 |
| 供电要足 | ESP32-CAM 峰值电流可达 500mA，电源要够 |
| 充电指示灯 | TP4056 红灯=充电中、蓝灯=充满，可边充边用 |
| WiFi 用 2.4GHz | ESP32 不支持 5GHz |
| 摄像头排线方向 | 金手指朝向板内，插反会损坏 |
| 风扇电流上限 | S8050 方案建议风扇 ≤0.3A；更大电流改用 MOS |
| 引脚已变更 | 风扇=GPIO13、红灯=GPIO14（原 12/13）；固件 `config.h` 已同步 |
