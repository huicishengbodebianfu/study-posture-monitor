## 0. 前置条件

开始之前，请确认你手头有：

| 类别 | 物品 | 说明 |
|------|------|------|
| 服务器 | 云服务器 | 阿里云/腾讯云轻量 2C4G，Ubuntu 22.04，**国内地域** |
| 硬件 | AI Thinker ESP32-CAM | **必须带 PSRAM** |
| 硬件 | USB-TTL 下载器 | CH340 或 CP2102 |
| 外设 | 5V 无刷涡轮鼓风机 + MOS 管/驱动板 | 用于吹风提醒 |
| 外设 | 红色 LED + 220Ω 电阻 | 用于视觉提醒 |
| 电池 | 18650(带保护板) + TP4056 + XL3608-5V | 可选，先用 USB 供电调试 |

> **建议**：第一次部署先用 USB 供电，跑通全链路后再上电池组，
> 这样能排除供电问题带来的干扰。

## 1. 云端部署（M3）

### 1.1 上传代码

把本地 `cloud/` 目录上传到服务器：

```bash
# 方式一：scp 直接拷贝
scp -r cloud/ user@server:/opt/posture

# 方式二：用 git（推荐，方便后续更新）
git clone <你的仓库地址> /opt/posture
```

> 把 `user` 换成你的服务器用户名，`server` 换成服务器公网 IP。

### 1.2 安装依赖

```bash
ssh user@server
cd /opt/posture
sudo apt update && sudo apt install -y python3-venv python3-pip
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 1.3 导出并放置模型

在本地（有网络的机器）执行：

```bash
pip install ultralytics
python -c "from ultralytics import YOLO; YOLO('yolov8n-pose.pt').export(format='openvino')"
```

将生成的 `yolov8n-pose_openvino_model/` 上传到 `/opt/posture/`：

```bash
scp -r yolov8n-pose_openvino_model/ user@server:/opt/posture/
```

### 1.4 配置并启动

```bash
cp .env.example .env
# 编辑 .env，设置 DEVICE_KEY（记下来，固件要用）
uvicorn app:app --host 0.0.0.0 --port 8000
```

> `DEVICE_KEY` 建议用随机字符串，例如：
> `openssl rand -hex 16` 生成一个。

### 1.5 验证

```bash
# 健康检查
curl http://localhost:8000/health
# 期望输出：{"status":"ok"}

# 上传一张测试图片
curl -X POST http://localhost:8000/detect \
  -H "X-Device-Key: 你的密钥" \
  -H "Content-Type: image/jpeg" \
  --data-binary @test.jpg
# 期望输出：{"action":"none","upright":true,...}
```

### 1.6 开放防火墙端口

```bash
# 云控制台安全组放行 8000 端口（或改用 80/443 + 反向代理）
sudo ufw allow 8000/tcp
```

> **重要**：除了服务器本机的 `ufw`，还要在**云控制台的安全组**里
> 放行 8000 端口，否则外网访问不到。

### 1.7 配置开机自启

```bash
sudo cp posture.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now posture
sudo systemctl status posture
```

看到 `active (running)` 即成功。

## 2. 固件烧录（M4）

1. Arduino IDE 安装 ESP32 开发板支持 + `esp32-camera` + `ArduinoJson`
   （详见 [../firmware/README.md](../firmware/README.md)）
2. 打开 `firmware/main.ino`
3. 修改 `firmware/config.h`：
   - `WIFI_SSID` / `WIFI_PASSWORD`：你的 WiFi（**2.4GHz**）
   - `SERVER_URL` = `http://服务器公网IP:8000/detect`
   - `DEVICE_KEY` = 云端 `.env` 中的值
4. 开发板选 `AI Thinker ESP32-CAM`，分区选 `Huge APP`
5. USB-TTL 接线，GPIO0 接 GND，按 RST，上传
6. 断开 GPIO0，按 RST 重启
7. 串口监视器 115200 查看日志

**正常日志**：

```
[WiFi] 已连接, IP=192.168.1.100
[CAM]  摄像头初始化成功
[UPLOAD] 上传成功, 响应: {"action":"none","upright":true}
```

## 3. 联调（M5）

1. 服务器 `journalctl -u posture -f` 观察是否收到帧
2. 坐直 → 应返回 `upright:true, action:none`
3. 刻意驼背约 20 秒 → 应返回 `action:blow`，风扇吹 5 秒
4. 按 BOOT 键 → 进入免打扰，5 分钟内不吹
5. 若误报/漏报，按 [标定流程.md](标定流程.md) 重新标定阈值

**验收清单**：

- [ ] 坐直时风扇不吹
- [ ] 刻意驼背约 20 秒后被吹 5 秒
- [ ] 按 BOOT 键后 5 分钟内不吹
- [ ] 免打扰期间再按 BOOT 键可提前恢复
- [ ] 服务器日志能看到每 10 秒一帧

## 4. 常见问题

| 现象 | 排查 |
|------|------|
| 固件上传失败 code=-1 | SERVER_URL 错误 / 安全组未放行 / WiFi 不通 |
| 固件上传失败 code=401 | DEVICE_KEY 不一致 |
| 服务器收不到帧 | 固件 WiFi 未连上；看串口日志 |
| 一直 no_person | 光照不足 / 人不在画面 / 摄像头对焦 |
| 风扇不转 | GPIO13 接线 / S8050/MOS 管 / 电机供电 |
| ESP32 频繁复位 | 供电不足，加大电容或换电源 |
| 服务起不来 | `journalctl -u posture -f` 看报错 |
| 外网访问不到 | 云控制台安全组是否放行 8000 |
