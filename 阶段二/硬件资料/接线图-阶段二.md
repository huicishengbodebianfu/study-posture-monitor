## 1. 供电链路（先接这一路，是地基）

```
18650 电池  ──▶  TP4056(带保护板)  ──▶  SX1308升压  ──▶  5V 母线
(B+/B−)        (B+/B− → OUT+/OUT−)    (IN+/IN− → OUT+/OUT−)    │
                                                                ├──▶ 1000µF 电解电容(正极接5V,负极GND)
                                                                ├──▶ ESP32-S3-CAM 的 5V 脚
                                                                └──▶ 风扇正极(经 S8050 开关)
```

| 模块 | 端子 | 接到 |
|---|---|---|
| 18650 | 正极 / 负极 | TP4056 `B+` / `B−` |
| TP4056 | `OUT+` / `OUT−` | SX1308 `IN+` / `IN−` |
| TP4056 | Micro-USB / Type-C 口 | 充电输入 |
| SX1308 | `OUT+` / `OUT−` | 5V 母线 / GND 母线 |
| 电源总开关(船型) | 串在**电池正极**与 TP4056 `B+` 之间 | 彻底断电用 |

**关键点**：
1. **电源总开关串在电池正极主回路**（18650 正极 → 船型开关 → TP4056 B+），不是串在 5V 输出侧。
2. **SX1308 到手先调 5V 再封电位器**（万用表量 OUT 两端 = 5.0V，热熔胶封死电位器）。
3. **1000µF 电容务必靠近 ESP32 的 5V 脚**，跨接 5V 与 GND（正极接 5V，负极接 GND），缓冲风扇启动尖峰。
4. 电容**正负极别接反**（长脚正、短脚负，外壳有负号标）。

## 2. 风扇驱动（S8050 三极管 + 续流二极管）

```
ESP32 GPIO21 ──▶ 220Ω ──▶ S8050 基极(B,中间脚)
                     │
                     └──▶ 10kΩ ──▶ GND   ← 下拉, 上电风扇不转

S8050 发射极(E,左脚) ──▶ GND 母线
S8050 集电极(C,右脚) ──▶ 风扇负极(黑线)
5V 母线             ──▶ 风扇正极(红线)

1N5819(肖特基)  ──▶ 带环端(阴极)──▶ 5V；另一端(阳极)──▶ 风扇负极(集电极)
                    ← 反向并联在风扇两端, 吸收断电尖峰
```

| 元件 | 规格 | 作用 |
|---|---|---|
| 开关管 | S8050（NPN，TO-92） | 小电流控制大电流 |
| 续流二极管 | 1N5819 | 吸收电机断电反向尖峰，**必须接**（三极管无体二极管） |
| 基极电阻 | 220Ω | 限流保护 GPIO |
| 下拉电阻 | 10kΩ | 上电默认关断风扇 |

**引脚识别（TO-92）**：有字面朝自己、引脚朝下，**从左到右 = E–B–C**（中间脚是 B）。

⚠️ **1N5819 方向**：**带环端必须朝 5V**，接反 = 风扇一开就短路烧管。焊接前务必核对。

## 3. 双色状态灯（共阴红绿 LED）

双色共阴 LED 有三只脚：**中间脚是公共阴极（接 GND）**，两边脚分别是红、绿阳极。

```
ESP32 GPIO14 ──▶ 220Ω ──▶ LED 红阳极(脚)
ESP32 GPIO47 ──▶ 220Ω ──▶ LED 绿阳极(脚)
GND           ──▶ LED 公共阴极(中间脚)
```

| 项 | 说明 |
|---|---|
| 电阻 | 红、绿各串 1 个 220Ω（不能省，否则烧 LED） |
| 极性 | 共阴，中间脚接 GND；若买成共阳则接法相反，先确认 |
| 颜色 | 红=吹风/免打扰，绿=正常，黄(红+绿同亮)=告警 |

**验证共阴**：万用表二极管档，黑表笔接中间脚、红表笔分别碰两边脚，能点亮 → 共阴。

## 4. 安静开关（拨动开关）

```
ESP32 GPIO47 ──▶ 拨动开关中间脚
拨动开关任一侧脚 ──▶ GND
```

- 拨到「安静」位 = 开关闭合 = GPIO47 读到 LOW = 进入免打扰
- 拨回 = 断开 = 内部上拉 HIGH = 恢复
- 无需外部电阻（固件已设 `INPUT_PULLUP`）

> MTS102 是 SPST 拨动开关，用中间脚 + 任一侧脚即可（另一侧脚悬空）。

## 4.5 0.96 OLED（I2C，中文显示）

扩展板 4 线 OLED 座子（GND / VDD / SCK / SDA），实测走线如下：

| OLED 座子 | 接到 ESP32 | 实测依据 |
|---|---|---|
| GND | GND | — |
| VDD | **3V3** | 万用表通断实测为 3V3（切勿接 5V，会烧屏） |
| SCK（=SCL） | **GPIO41** | 2026-11-08 通断实测 |
| SDA | **GPIO42** | 2026-11-08 通断实测 |

**固件已做的兜底**：
- 构造函数显式传引脚（避免 U8g2 内部 `Wire.begin()` 回到 GPIO8/9，那是摄像头脚）
- I2C 地址 0x3C / 0x3D 自动探测
- SDA/SCL 接反自动纠正
- `GET /i2cscan` 远程扫描 I2C 总线，判断屏是否被认到

**OLED 不亮排查**：浏览器打开 `http://<板子IP>/i2cscan`
- 出现 `found 0x3C`/`0x3D` → 屏被认到，查 VDD 电压/屏本身
- 只有 `done` → 接线不通（GND/3V3/SCK/SDA 任一根没通）

## 5. 电池电量 ADC（分压）

```
18650 正极 ──▶ 10kΩ(上) ──┬──▶ 10kΩ(下) ──▶ GND
                          │
                          └──▶ ESP32 GPIO1 (ADC1_CH0)
```

- 分压比 1:1，满电 4.2V → 采样约 2.1V（安全，<3.3V ADC 上限）
- 两根 10kΩ 电阻；采样点接 GPIO1

## 7. 接线顺序建议（分步验收，别一次全焊）

| 步骤 | 内容 | 验收标准 |
|---|---|---|
| ① | 供电链路（电池→开关→TP4056→SX1308→5V→ESP32 5V） | 板上电，串口有 `[BOOT]` 输出 |
| ② | 只接 LED（GPIO14 红 / GPIO2 绿，各串 220Ω） | 开机自检红绿各闪一次 |
| ③ | 只接风扇（S8050 + 1N5819） | 自检时风扇 200ms 脉冲转一下 |
| ④ | 接安静开关（GPIO47） | 拨到安静位 → 红灯常亮 + `/status` 显示 quiet_switch=true |
| ⑤ | 接电池 ADC（GPIO1 分压） | `/status` 显示 battery_v ≈ 实际电压 |
| ⑥ | 接 OLED（GPIO41=SCK / GPIO42=SDA） | OLED 显示"学习坐姿监测"；不亮看 `/i2cscan` |

**每步只焊一样，测通再焊下一样**，出问题好排查。

## 8. 注意事项

| 事项 | 说明 |
|---|---|
| 电机不能直连 GPIO | 必须经 S8050，否则烧芯片 |
| 1N5819 方向 | 带环端朝 5V，反向并联风扇两端 |
| S8050 引脚 | 有字面朝自己 = E–B–C（中间 B） |
| S8050 vs S8550 | 用 NPN 的 S8050，别拿成 PNP 的 S8550 |
| 电池正负极 | TP4056 反接会烧保护板，焊前量电压 |
| LED 必须串电阻 | 红绿各 220Ω，否则烧 LED |
| 5V 加大电容 | 1000µF 靠近 ESP32 5V 脚 |
| SX1308 调压 | 先调到 5.0V 再封死电位器 |
| PSRAM 脚 | GPIO35/36/37 绝不外接 |
| 摄像头排线 | 已接好，勿动；若拆过，金手指朝板内 |
| 供电要足 | 峰值 500mA+，USB 供电要用 2A 口或电池 |
