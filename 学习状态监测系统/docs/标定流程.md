# 阈值标定流程

判定坐姿是否端正，靠的是两个数值阈值。默认值是"经验值"，
不一定适合你的摄像头位置、身高和坐姿习惯。本文档说明如何用
**你自己的照片**标定出合适的阈值。

## 1. 为什么要标定

系统判定"端正/不端正"用的是两个数值：

- **头高**（head_height）：低于某个值 → 判为低头/驼背
- **肩平差**（shoulder_level）：高于某个值 → 判为侧歪

这两个"某个值"就是**阈值**。默认阈值是拍脑袋定的经验值，
但每个人的情况不同：

- 摄像头高度、角度不同 → 特征数值分布不同
- 身高、坐姿习惯不同 → 端正时的数值也不同
- 桌子高度、椅子高度不同 → 影响更大

**不标定的后果**：要么频繁误报（坐得好好的也被吹），
要么完全漏报（驼背半天也不吹）。所以**强烈建议标定一次**。

---

## 2. 两个特征是什么

### 2.1 头高（head_height）

```
头高 = 肩中点Y − 鼻Y   （归一化到 0~1）
```

- **坐直时**：头在肩膀上方，头高较大
- **低头/驼背时**：头往下缩，头高变小

所以：**头高 < 阈值 → 判为低头/驼背**

### 2.2 肩平差（shoulder_level）

```
肩平差 = |左肩Y − 右肩Y|   （归一化到 0~1）
```

- **坐正时**：两肩齐平，差值很小
- **侧歪时**：一肩高一肩低，差值变大

所以：**肩平差 > 阈值 → 判为侧歪**

> **归一化是什么意思？**
> 把像素坐标除以图像宽高，变成 0~1 的比例。
> 这样不管图像分辨率多少，数值含义一致，阈值可复用。

## 3. 采集样本

### 3.1 用 CameraWebServer 抓帧

1. 在 Arduino IDE 里烧录 `CameraWebServer` 示例
2. 串口日志里找到局域网 IP
3. 浏览器打开该 IP，进入 MJPEG 流页面
4. 保持**实际使用时的摄像头位置**（桌上正对面，距头 0.5~0.6m）

### 3.2 分两组各抓 30 张

| 组别 | 目录 | 要求 |
|------|------|------|
| 端正组 | `samples/upright/` | 自然坐直，正常学习姿势 |
| 不端正组 | `samples/slouch/` | 刻意低头/驼背/侧歪 |

**采集要点**：

- 两组要在**同一位置、同一光照**下采集
- 端正组要"自然端正"，不要刻意挺得笔直
- 不端正组要覆盖你**实际会出现的**不端正姿势
- 每组 30 张，尽量有变化（不要 30 张一模一样）

> **为什么各要 30 张？**
> 样本太少，统计分布不可靠；30 张能算出有意义的 P5/P95 分位数。

## 4. 运行标定脚本

```bash
cd cloud
source venv/bin/activate
python calibrate.py --upright ./samples/upright --slouch ./samples/slouch
```

脚本会对每张图推理，提取特征，然后统计两组的分布。

---

## 5. 理解输出

脚本会输出类似这样的结果：

```
=== 端正组 (upright) ===
head_height:     mean=0.21  P5=0.17  P50=0.21  P95=0.25
shoulder_level:  mean=0.01  P5=0.00  P50=0.01  P95=0.03

=== 不端正组 (slouch) ===
head_height:     mean=0.09  P5=0.05  P50=0.09  P95=0.13
shoulder_level:  mean=0.06  P5=0.02  P50=0.06  P95=0.11

=== 建议阈值 ===
HEAD_HEIGHT_MIN   = 0.15   (端正组P5 与 不端正组P95 的中间值)
SHOULDER_LEVEL_MAX = 0.045
```

**怎么读**：

- **P5**：5% 的样本低于这个值（即"最不端正的端正样本"）
- **P95**：95% 的样本低于这个值（即"最端正的不端正样本"）
- 建议阈值取两组之间的**中间值**，这样两组都能较好区分

> **为什么取中间值？**
> 端正组的最低值（P5）和不端正组的最高值（P95）之间有一段"模糊地带"。
> 取中间值能让误报和漏报都尽量少。

---

## 6. 应用阈值

把建议阈值写入配置。有两种方式：

**方式一：改 `.env`**（推荐）

```bash
# 编辑 .env
HEAD_HEIGHT_MIN=0.15
SHOULDER_LEVEL_MAX=0.045
```

**方式二：改 `posture.service`**

在 `Environment=` 行里加上这两个变量。

改完后重启服务：

```bash
sudo systemctl restart posture
```

## 7. 实测验证

标定后必须实测，验收标准：

| 测试 | 期望结果 |
|------|----------|
| 自然坐直 1 分钟 | 风扇**不吹** |
| 刻意驼背约 20 秒 | 风扇**吹 5 秒** |
| 刻意侧歪约 20 秒 | 风扇**吹 5 秒** |
| 按 BOOT 键 | 5 分钟内**不吹** |
| 免打扰期间再按 BOOT | 立即恢复监测 |

> **为什么是"约 20 秒"？**
> 因为规则是"连续 2 帧不端正"，每帧间隔 10 秒，所以约 20 秒触发。

---

## 8. 微调技巧

如果实测结果不理想，按下面方向调整：

| 问题 | 调整方向 |
|------|----------|
| 误报太多（坐直也被吹） | **调低** `HEAD_HEIGHT_MIN`（更宽松） |
| 漏报（驼背不吹） | **调高** `HEAD_HEIGHT_MIN`（更严格） |
| 侧歪误报 | **调高** `SHOULDER_LEVEL_MAX` |
| 侧歪漏报 | **调低** `SHOULDER_LEVEL_MAX` |

**调整原则**：

- **先松后紧**：初期宁可漏报，也别频繁误报（烦人）
- **小步调整**：每次改 0.01~0.02，观察效果
- **记录变化**：改一次测一次，别一次改太多

> **提示**：如果怎么调都不理想，可能是摄像头位置或光照问题。
> 检查摄像头是否正对、距离是否合适、光照是否充足。
