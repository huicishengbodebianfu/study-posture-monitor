## 先看这三条

1. **OLED 是采购清单漏项**：固件已启用 0.96" OLED；先确认扩展板是否自带屏，否则补买 SSD1306 I2C 4 针 **3.3V** 模块。
2. **OLED VDD 实测不通**：必须从主板 3V3 飞线到 OLED 座 VDD，**切勿接 5V**。
3. **引脚以 config.h 为准**：风扇 21、红灯 14、绿灯 2、开关 47、电池 ADC 1、OLED SCL 41 / SDA 42。
   旧图正文的“绿灯 47、开关 41”已过时。

## 施工顺序（详见定稿文档 §12）

供电 → 烧录 → 双色灯 → 风扇 → 安静开关 → 电池 ADC → OLED → 相机/云端联调。
**每步测通再焊下一路**，不要一次全焊。

> 当前无升压：先按应急图接 **5V USB 直供**，再按 ①~⑨ 验收；电池断开时 OLED 显示 `BAT --` 属正常。
